# ذهب لايف — مراقبة الذهب لحظياً (PWA)

تطبيق ويب تقدّمي (PWA) عربي RTL للجوال أولاً: أسعار الذهب لحظياً بالريال لكل العيارات، تنبيهات شخصية تصل كإشعار حتى لو التطبيق مغلق، قراءة فنية آلية للسوق، ولوحة أدمن لإدارة المستخدمين بالدعوات.

**التقنيات:** Next.js 16 (App Router) + TypeScript + Tailwind 4 · Supabase (Auth OTP + Postgres + RLS + Realtime) · Vercel + Cron · Web Push (VAPID) · Telegram (اختياري) · Claude API (اختياري).

## المزايا

| القسم | التفاصيل |
|---|---|
| **الرئيسية** | سعر الأونصة كبير يومض أخضر/أحمر عند التغيّر، التغير منذ افتتاح اليوم، مؤشر «مباشر»، جدول العيارات 24/22/21/18 (شراء/بيع/الفرق/سعر المحل) بالريال/غرام |
| **الشارت** | رسم من بياناتنا (يوم/أسبوع/شهر/3 أشهر/سنة) + شارت TradingView لـ OANDA:XAUUSD |
| **الحاسبة** | وزن + عيار ← قيمة البيع والشراء وسعر المحل التقديري |
| **التنبيهات** | سعر الأونصة أعلى/أقل · سعر غرام عيار معيّن (شراء/بيع) أعلى/أقل · صعود/هبوط بنسبة X% خلال ساعة أو 24 ساعة أو منذ افتتاح اليوم · مرة واحدة أو متكرر مع فترة تهدئة · Web Push و/أو تيليجرام · سجل التنبيهات |
| **قراءة السوق** | المتوسطات 20/50/200، RSI(14)، التغير اليومي والأسبوعي، دعم ومقاومة آخر 30 يوماً، إشارة «فرصة شراء محتملة / محايد / فرصة بيع محتملة» مع الأسباب بالعربي، ملخص يومي اختياري من Claude |
| **لوحة الأدمن** | دعوة برابط أو بالإيميل، موافقة/إيقاف/حذف/ترقية، المصنعية وهامش المحل لكل عيار، سعر الدولار، إشعار لكل المستخدمين، سجل الدخول، حالة مصادر الأسعار |

**مصادر الأسعار** (من السيرفر فقط، بالترتيب مع fallback):
1. GoldAPI.io (spot + bid + ask)
2. API Ninjas
3. gold-api.com (spot فقط، بدون مفتاح)

كل مصدر يُعاد طلبه مرة عند أخطاء الشبكة/5xx مع انتظار تصاعدي، وتُرفض القيم غير المنطقية (قفزة أكثر من 15%، bid > ask…). إذا رجع مصدر بخطأ مفتاح أو تجاوز حصة (400/401/403/429) يتوقف 30 دقيقة تلقائياً (circuit breaker)، وبعد 3 أخطاء متتالية يتوقف مؤقتاً بشكل متدرّج. كل سعر يُحفظ في `price_ticks`.

## الإعداد خطوة بخطوة

### 1) إنشاء مشروع Supabase

1. ادخل [supabase.com](https://supabase.com) ← **New project**. اختر منطقة قريبة (مثلاً Frankfurt أو Mumbai) وكلمة مرور قوية لقاعدة البيانات.
2. **إنشاء الجداول:** افتح **SQL Editor** ← **New query** ← الصق محتوى `supabase/migrations/0001_init.sql` كاملاً ← **Run**.
   - (أو عبر CLI: `npx supabase link --project-ref <ref>` ثم `npx supabase db push`)
3. **المفاتيح:** **Project Settings ← API** (أو **API Keys**):
   - `Project URL` ← `NEXT_PUBLIC_SUPABASE_URL`
   - `anon` / `publishable` ← `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role` / `secret` ← `SUPABASE_SERVICE_ROLE_KEY` (**سرّي — للسيرفر فقط**)
4. **إغلاق التسجيل:** **Authentication ← Sign In / Providers**:
   - فعّل **Email**.
   - **أطفئ** «Allow new users to sign up». (الحسابات تُنشأ فقط من السيرفر عند قبول دعوة.)
5. **رمز OTP في البريد:** **Authentication ← Emails ← Templates ← Magic Link**، واجعل القالب يحتوي الرمز، مثلاً:
   ```html
   <h2>رمز الدخول إلى ذهب لايف</h2>
   <p style="font-size:28px;letter-spacing:6px"><b>{{ .Token }}</b></p>
   <p>أو اضغط: <a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email">دخول</a></p>
   ```
   وفي قالب **Invite user**:
   ```html
   <h2>تمت دعوتك إلى ذهب لايف</h2>
   <p><a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=invite">قبول الدعوة والدخول</a></p>
   <p>أو افتح التطبيق وسجّل الدخول ببريدك وسيصلك رمز.</p>
   ```
6. **الروابط:** **Authentication ← URL Configuration**:
   - Site URL = رابط التطبيق على Vercel (مثل `https://gold.vercel.app`)
   - Redirect URLs: أضف `https://gold.vercel.app/**` و `http://localhost:3000/**`
7. **(موصى به) SMTP خاص:** بريد Supabase الافتراضي محدود بعدد قليل من الرسائل في الساعة. للاستخدام الفعلي اربط SMTP من **Authentication ← Emails ← SMTP Settings** (Resend، Brevo، Gmail App Password…).
8. **Realtime:** المايغريشن يضيف `price_ticks` إلى `supabase_realtime` تلقائياً. تأكد من ظهوره في **Database ← Publications**. إذا لم يعمل Realtime فالتطبيق يحدّث السعر كل 20 ثانية تلقائياً.

### 2) مفاتيح مصادر الأسعار

| المصدر | المفتاح | ملاحظة |
|---|---|---|
| [GoldAPI.io](https://www.goldapi.io) | `GOLDAPI_KEY` | يعطي bid/ask حقيقية. **الخطة المجانية محدودة جداً** (حوالي 100 طلب/شهر) فتنفد سريعاً مع الطلب كل دقيقة، وعندها ينتقل التطبيق تلقائياً للمصدر التالي. للاستخدام المستمر يلزم اشتراك مدفوع. |
| [API Ninjas](https://api-ninjas.com) | `API_NINJAS_KEY` | spot فقط. يمكن تغيير الرابط عبر `API_NINJAS_URL`. |
| [gold-api.com](https://gold-api.com) | — | بدون مفتاح، spot فقط. يكفي وحده لتشغيل التطبيق. |

عند غياب bid/ask يحسبها التطبيق من الفرق التقديري (`fallback_spread_usd`) الذي يضبطه الأدمن، ويظهر «تقديري» بجانب السعر.

### 3) توليد مفاتيح VAPID (للإشعارات)

```bash
npm install
npx web-push generate-vapid-keys
```
- `Public Key` ← `NEXT_PUBLIC_VAPID_PUBLIC_KEY`
- `Private Key` ← `VAPID_PRIVATE_KEY`
- `VAPID_SUBJECT=mailto:بريدك`

> لا تغيّر المفاتيح بعد الإطلاق، وإلا يلزم كل مستخدم تفعيل الإشعارات من جديد.

### 4) التشغيل محلياً

```bash
cp .env.example .env.local      # واملأ القيم
npm install
npm run dev                     # http://localhost:3000
```
`CRON_SECRET`: أي نص عشوائي طويل، مثلاً `openssl rand -hex 32`.

لتجربة جلب السعر وفحص التنبيهات يدوياً:
```bash
curl -H "Authorization: Bearer $CRON_SECRET" http://localhost:3000/api/cron/tick
```
(حتى بدون جدولة، تجلب الصفحة الرئيسية سعراً جديداً تلقائياً إذا كان آخر سعر أقدم من دقيقتين ونصف. لكن **التنبيهات تحتاج الجدولة**.)

> الإشعارات تتطلب HTTPS، فجرّبها على رابط Vercel وليس على localhost من الجوال.

### 5) الرفع على Vercel

1. ارفع المستودع على GitHub.
2. [vercel.com/new](https://vercel.com/new) ← استورد المستودع (Framework: Next.js، بدون تغيير الإعدادات).
3. **Settings ← Environment Variables**: أضف كل متغيرات `.env.example` (Production + Preview). تأكد أن `NEXT_PUBLIC_SITE_URL` هو رابط النشر النهائي.
4. **Deploy**.
5. ارجع إلى Supabase وحدّث **Site URL** و **Redirect URLs** بالرابط النهائي (الخطوة 1.6).

### 6) الجدولة كل دقيقة

`vercel.json` يحتوي:
```json
{ "path": "/api/cron/tick", "schedule": "* * * * *" }
```
Vercel يرسل تلقائياً `Authorization: Bearer $CRON_SECRET`.

- **خطة Vercel Pro:** يعمل كل دقيقة مباشرة.
- **خطة Hobby (المجانية):** Vercel يسمح بجدولة يومية فقط، وقد يرفض النشر بسبب `* * * * *`. في هذه الحالة:
  1. احذف سطر `/api/cron/tick` من `vercel.json` (أو اجعله `0 0 * * *`).
  2. استخدم جدولة Supabase بدلاً منه: افتح `supabase/cron.sql`، ضع رابط تطبيقك و `CRON_SECRET`، ثم شغّله في **SQL Editor**. يستعمل `pg_cron` + `pg_net` لاستدعاء `/api/cron/tick` كل دقيقة، والسر محفوظ في Vault.

للتحقق: **لوحة الأدمن ← حالة مصادر الأسعار** تعرض وقت آخر سعر محفوظ والمصدر.

### 7) أول دخول كأدمن

1. ضع بريدك في `ADMIN_EMAIL`.
2. افتح التطبيق ← أدخل بريدك ← سيصلك رمز ← أدخله.
3. أول دخول بهذا البريد يُنشئ الحساب تلقائياً **كأدمن فعّال** (ويُعاد تأكيد الصلاحية عند كل دخول).
4. من **لوحة الأدمن**:
   - **رابط دعوة:** عدد الاستخدامات ومدة الصلاحية، ثم شاركه (واتساب…).
   - **دعوة بالإيميل:** تُرسل دعوة عبر Supabase، ويستطيع المدعو الدخول بالرمز مباشرة.
   - «تفعيل الحساب تلقائياً»: إن ألغيته، يدخل المدعو في حالة «بانتظار الموافقة» حتى توافق عليه.
   - اضبط سعر الدولار (الافتراضي 3.75)، والمصنعية (ر.س/غ) وهامش المحل (%) لكل عيار.

### 8) تيليجرام (اختياري)

1. في تيليجرام افتح [@BotFather](https://t.me/BotFather) ← `/newbot` ← احفظ التوكن واسم البوت.
2. أضف المتغيرات في Vercel:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   TELEGRAM_BOT_USERNAME=MyGoldBot
   TELEGRAM_WEBHOOK_SECRET=<نص عشوائي: أحرف وأرقام و _ و - فقط>
   ```
3. سجّل الـ webhook (مرة واحدة بعد النشر):
   ```bash
   curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook" \
     -d "url=https://YOUR-APP.vercel.app/api/telegram/webhook" \
     -d "secret_token=$TELEGRAM_WEBHOOK_SECRET"
   ```
4. كل مستخدم: **الإعدادات ← ربط تيليجرام** ← يفتح البوت ← **Start**. بعدها يستطيع اختيار تيليجرام كقناة في التنبيهات.

### 9) الملخص اليومي من Claude (اختياري)

1. أنشئ مفتاحاً من [console.anthropic.com](https://console.anthropic.com) ← `ANTHROPIC_API_KEY`.
2. في **لوحة الأدمن** فعّل «الملخص اليومي بالذكاء الاصطناعي».
3. يُكتب الملخص يومياً الساعة 7 صباحاً بتوقيت الرياض عبر `/api/cron/daily-summary`، ويظهر في «قراءة السوق». النموذج الافتراضي `claude-opus-5-5` (قابل للتغيير عبر `ANTHROPIC_MODEL`)، مع تفعيل التحويل التلقائي لنموذج بديل إذا رفض النموذج الطلب.

## تثبيت التطبيق على الجوال

### الآيفون (Safari، iOS 16.4 أو أحدث)
1. افتح رابط التطبيق في **Safari** (وليس Chrome).
2. اضغط زر **المشاركة** ⬆️ أسفل الشاشة.
3. اختر **«إضافة إلى الشاشة الرئيسية»** ← **إضافة**.
4. **افتح التطبيق من الأيقونة** الجديدة وسجّل الدخول.
5. **الإعدادات ← تفعيل الإشعارات على هذا الجهاز** ← **سماح**.
6. اضغط «إرسال إشعار تجريبي» للتأكد.

> على الآيفون لا تعمل الإشعارات إلا من التطبيق المثبّت على الشاشة الرئيسية، لا من Safari مباشرة.

### أندرويد (Chrome)
1. افتح الرابط في Chrome ← القائمة ⋮ ← **تثبيت التطبيق** (أو زر «تثبيت على الجهاز» في الإعدادات).
2. افتحه ← **الإعدادات ← تفعيل الإشعارات**.

## الحسابات والمعادلات

- الأونصة = **31.1035** غرام.
- النقاوة: 24 = 1 · 22 = 0.916 · 21 = 0.875 · 18 = 0.75.
- `غرام العيار (ر.س) = (سعر الأونصة $ ÷ 31.1035) × النقاوة × سعر الدولار`
- **شراء** على ask، **بيع** على bid، **الفرق** = شراء − بيع.
- **سعر المحل التقديري** = `(شراء + المصنعية) × (1 + الهامش%)`.
- «افتتاح اليوم» = أول سعر بعد منتصف الليل بتوقيت `APP_TIMEZONE` (الافتراضي Asia/Riyadh).

**قراءة السوق:** تُحسب المؤشرات على شموع الساعة حتى يتجمّع 50 يوماً من البيانات، ثم على الشموع اليومية تلقائياً. الإشارة مجموع نقاط:
RSI < 30 (+2) / > 70 (−2)، RSI بين 30–40 (+0.5) / 60–70 (−0.5)، قرب الدعم ≤ 0.6% (+1)، قرب المقاومة (−1)، متوسط 50 فوق/تحت 200 (±0.5)، ابتعاد السعر أكثر من 1.5% عن متوسط 20 (±0.5).
الناتج ≥ 2 «فرصة شراء محتملة»، ≤ −2 «فرصة بيع محتملة»، غير ذلك «محايد».
**هذه قراءة فنية آلية وليست نصيحة استثمارية.**

## الأمان والصلاحيات

- **RLS على كل الجداول:** المستخدم يرى ويعدّل تنبيهاته فقط، والأدمن يقرأ الكل. المستخدم غير المفعّل (pending/suspended) لا يقرأ الأسعار ولا ينشئ تنبيهات.
- لا يستطيع المستخدم تغيير دوره أو حالته (صلاحيات على مستوى العمود: يعدّل `display_name` فقط).
- الدور والحالة عند إنشاء الحساب يأتيان من `app_metadata` التي يكتبها السيرفر فقط. أي حساب يُنشأ بطريقة أخرى يصبح «مشاهد بانتظار الموافقة».
- الدعوات تُستهلك ذرّياً (`consume_invite`) مع حدّ للاستخدامات وتاريخ انتهاء، ويمكن إلغاؤها.
- مفاتيح المصادر و `service_role` و VAPID الخاص في متغيرات السيرفر فقط، وكل نداءات الأسعار من السيرفر.
- `/api/cron/*` محمي بـ `CRON_SECRET` (مقارنة ثابتة الوقت)، والـ webhook محمي بـ `secret_token`.
- لا يمكن تعديل أو حذف حساب `ADMIN_EMAIL` من اللوحة.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
