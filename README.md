# ذهب لايف — أسعار الذهب (PWA)

تطبيق ويب عربي (RTL) لمراقبة أسعار الذهب، مصمم للآيفون أولاً. HTML + CSS + JavaScript فقط، بدون build، ويعمل مباشرة على GitHub Pages.

- سعر الأونصة بالدولار والريال (3.75)، وسعر الجرام لعيارات 24 / 22 / 21 / 18، مع نسبة التغيّر اليوم.
- منحنى آخر 24 ساعة (SVG بدون مكتبات)، المسه لعرض السعر في أي وقت.
- تحديث تلقائي كل 30 ثانية وزر تحديث يدوي.
- **التنبيهات:** عيار + «أعلى من» أو «أقل من» + سعر الجرام. عند تحقق الشرط يظهر إشعار على الشاشة مع صوت، واهتزاز إن كان الجهاز يدعمه.
- **مشترياتي:** القيمة الحالية والربح/الخسارة لكل عملية وللإجمالي.
- يعمل بدون إنترنت: يعرض آخر سعر محفوظ مع وقت آخر تحديث.
- التنبيهات والمشتريات محفوظة على الجهاز (localStorage)، ولا تُرسل لأي خادم.

مصدر الأسعار: [xaus.com](https://xaus.com/api) (مجاني، بدون مفتاح).
السعر عالمي، ولا يشمل المصنعية وضريبة القيمة المضافة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة |
| `styles.css` | التصميم (داكن ذهبي) |
| `app.js` | المنطق: الأسعار، المنحنى، التنبيهات، المشتريات |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `manifest.json`, `icons/` | التثبيت على الشاشة الرئيسية |
| `404.html` | أي رابط خاطئ داخل الموقع يرجع للتطبيق |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات بـ Jekyll |
| `tests/e2e.cjs` | اختبار آلي على محاكاة آيفون (Playwright) |
| `nextjs-app/` | النسخة السابقة المتقدمة (Next.js + Supabase). لا علاقة لها بهذا التطبيق ويمكن حذفها |

## التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## تفعيل GitHub Pages

1. افتح المستودع على GitHub ← **Settings** ← **Pages**.
2. في **Build and deployment** ← **Source** اختر **Deploy from a branch**.
3. **Branch:** اختر `main` والمجلد `/ (root)` ← **Save**.
4. انتظر دقيقة أو دقيقتين، ثم حدّث الصفحة. سيظهر الرابط بالشكل:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

> GitHub Pages مجاني للمستودعات العامة (Public). إذا كان المستودع خاصاً، تحتاج خطة مدفوعة أو تجعله عاماً.

## التثبيت على الآيفون

1. افتح الرابط في **Safari**.
2. اضغط زر **المشاركة** ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← **إضافة**.
3. افتح التطبيق من الأيقونة.

ملاحظات:
- التنبيهات تعمل **أثناء فتح التطبيق**. الآيفون لا يسمح لتطبيقات الويب بفحص الأسعار في الخلفية بدون خادم.
- الصوت يعمل بعد أول لمسة في التطبيق (قيد في iOS).
- الآيفون لا يدعم الاهتزاز لتطبيقات الويب. يعمل على أندرويد.
- زر «تفعيل إشعارات النظام» في صفحة التنبيهات يظهر في التطبيق المثبّت (iOS 16.4+)، ليظهر التنبيه في مركز الإشعارات أيضاً.

## التحديثات

عند تعديل أي ملف، غيّر `VERSION` في `sw.js` (مثلاً `v2`) ليحصل المستخدمون على النسخة الجديدة.

## الاختبار

```bash
npm i -g playwright   # إن لم يكن مثبتاً
node tests/e2e.cjs
```
