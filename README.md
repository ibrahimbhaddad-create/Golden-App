# ذهب لايف — أسعار الذهب (PWA)

تطبيق ويب عربي (RTL) لمراقبة أسعار الذهب، مصمم للآيفون أولاً. HTML + CSS + JavaScript فقط، بدون build، ويعمل مباشرة على GitHub Pages.

**الأسعار**
- أونصة الذهب بالدولار وبعملتك، وسعر الجرام لعيارات 24 / 22 / 21 / 18، مع نسبة التغيّر اليوم.
- **الفضة:** سعر الأونصة، وجرام فضة 999 و925.
- **سعر المحل التقديري** لكل عيار = السعر العالمي + المصنعية (تحددها أنت) + ضريبة القيمة المضافة (15% قابلة للتعديل).
- **13 عملة:** ريال سعودي (ثابت 3.75)، درهم، دينار كويتي/بحريني/أردني/عراقي، ريال قطري/عماني، جنيه مصري، دولار، يورو، إسترليني، ليرة تركية.
- تحديث تلقائي كل 30 ثانية وزر تحديث يدوي.

**السعر المباشر والشارت**
- **سعر لحظي يتحرك مع كل صفقة** (يومض أخضر/أحمر) من تداول XAUT وPAXG (عملات مضمونة بالذهب، كل وحدة = أونصة) على Binance، **معدّل تلقائياً على السعر العالمي** من xaus.com.
- **وقت إغلاق السوق العالمي** (الويكند والاستراحة اليومية) يبقى السعر على الإغلاق الرسمي ويظهر «السوق مغلق».
- إذا انقطع البث يرجع تلقائياً للتحديث كل دقيقة من xaus.com، ويعيد الاتصال.
- شموع **ثانية / دقيقة / 5 دقائق / 15 دقيقة / ساعة / 4 ساعات** تتحدّث لحظياً، و**يوم / أسبوع** من السعر العالمي حتى 5 سنوات.
- المس أي شمعة لعرض الافتتاح والأعلى والأدنى والإغلاق، وجدول أسعار تاريخية بالأونصة أو بجرام أي عيار وبعملتك.
- زر **شارت TradingView** المتقدم (يحتاج إنترنت).

**الحاسبة**
- الوزن والعيار (ذهب أو فضة) ← القيمة العالمية + المصنعية + الضريبة = السعر التقديري في المحل.

**التنبيهات**
- سعر جرام عيار معيّن، أو سعر أونصة الذهب/الفضة، أو نسبة صعود/نزول الذهب اليوم.
- مرة واحدة أو متكرر (كل 15 دقيقة / ساعة / 3 ساعات / يوم كحد أقصى).
- إشعار على الشاشة + صوت + اهتزاز إن أمكن، وإشعار النظام اختيارياً.

**مشترياتي**
- التاريخ، العيار (ذهب أو فضة)، الوزن، المدفوع، وملاحظة.
- القيمة الحالية والربح/الخسارة لكل عملية وللإجمالي، ومتوسط سعر الجرام.
- **تسجيل البيع** وحساب الربح المحقق.
- متوسط تكلفة جرام الذهب الخالص مقارنة بسعره الآن.

**أخرى**
- **نسخة احتياطية:** تصدير واستيراد كل البيانات بملف (من الإعدادات).
- يعمل بدون إنترنت: يعرض آخر سعر وشارت محفوظين مع وقت آخر تحديث.
- كل البيانات محفوظة على جهازك (localStorage)، ولا تُرسل لأي خادم.

مصدر الأسعار: [xaus.com](https://xaus.com/api) (مجاني، بدون مفتاح): `spot` و`intraday` و`history`.
السعر عالمي، ولا يشمل المصنعية وضريبة القيمة المضافة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة |
| `styles.css` | التصميم (داكن ذهبي) |
| `app.js` | المنطق: الأسعار، الشارت، الحاسبة، التنبيهات، المشتريات، الإعدادات |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `manifest.json`, `icons/` | التثبيت على الشاشة الرئيسية |
| `404.html` | أي رابط خاطئ داخل الموقع يرجع للتطبيق |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات بـ Jekyll |
| `tests/e2e.cjs` | اختبار آلي على محاكاة آيفون (Playwright) |
| `worker/` | خادم التنبيهات بالخلفية (Cloudflare Worker) |
| `config.json` | عنوان خادم التنبيهات (يكتبه GitHub Actions تلقائياً) |
| `nextjs-app/` | النسخة السابقة المتقدمة (Next.js + Supabase). لا علاقة لها بهذا التطبيق ويمكن حذفها |

## التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## تفعيل GitHub Pages

1. افتح المستودع على GitHub ← **Settings** ← **Pages**.
2. في **Build and deployment** ← **Source** اختر **Deploy from a branch**.
3. **Branch:** اختر `main` والمجلد `/ (root)` ← **Save**.
4. انتظر دقيقة أو دقيقتين، ثم حدّث الصفحة. سيظهر الرابط بالشكل:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

> GitHub Pages مجاني للمستودعات العامة (Public). إذا كان المستودع خاصاً، تحتاج خطة مدفوعة أو تجعله عاماً.

## التثبيت على الآيفون

1. افتح الرابط في **Safari**.
2. اضغط زر **المشاركة** ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← **إضافة**.
3. افتح التطبيق من الأيقونة.

ملاحظات:
- بدون خادم، التنبيهات تعمل **أثناء فتح التطبيق** فقط. لتصلك والتطبيق مسكّر فعّل [التنبيهات بالخلفية](#تنبيهات-بالخلفية-حتى-لو-التطبيق-مسكّر).
- الصوت يعمل بعد أول لمسة في التطبيق (قيد في iOS).
- الآيفون لا يدعم الاهتزاز لتطبيقات الويب. يعمل على أندرويد.
- زر «تفعيل إشعارات النظام» في صفحة التنبيهات يظهر في التطبيق المثبّت (iOS 16.4+)، ليظهر التنبيه في مركز الإشعارات أيضاً.

## تنبيهات بالخلفية (حتى لو التطبيق مسكّر)

خادم صغير مجاني على **Cloudflare Workers** (مجلد `worker/`) يفحص السعر كل دقيقة، ويرسل إشعار Web Push لكل جهاز فعّل الميزة. يُنشر تلقائياً من GitHub Actions (`.github/workflows/deploy-worker.yml`)، والتطبيق يقرأ عنوانه من `config.json`.

### الإعداد (مرة واحدة)

1. **حساب Cloudflare:** سجّل مجاناً على [dash.cloudflare.com](https://dash.cloudflare.com/sign-up).
2. **نطاق workers.dev:** من القائمة افتح **Workers & Pages** مرة واحدة، واختر اسماً للنطاق الفرعي إذا طُلب منك.
3. **Account ID:** في صفحة **Workers & Pages** تجده على اليمين، انسخه.
4. **API Token:** صورتك (أعلى اليمين) ← **My Profile** ← **API Tokens** ← **Create Token** ← قالب **Edit Cloudflare Workers** ← **Use template** ← في **Account Resources** اختر حسابك ← **Continue to summary** ← **Create Token**، وانسخ التوكن (يظهر مرة واحدة).
5. **أسرار GitHub:** في المستودع: **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**، وأضف:
   - `CLOUDFLARE_API_TOKEN` = التوكن
   - `CLOUDFLARE_ACCOUNT_ID` = رقم الحساب
6. **النشر:** **Actions** ← **Deploy alerts server** ← **Run workflow**. يختبر الخادم وينشره، ثم يكتب عنوانه في `config.json` تلقائياً.
7. **على الآيفون:** بعد دقيقتين افتح التطبيق من الأيقونة ← **الإعدادات** ← **تفعيل التنبيهات بالخلفية** ← **السماح**، ثم «إرسال إشعار تجريبي».

### كيف يعمل
- مفاتيح VAPID يولّدها الخادم أول مرة ويحفظها، فلا تحتاج لإدخال أي مفتاح.
- كل جهاز يسجّل اشتراكه، والتطبيق يرسل تنبيهاته للخادم عند كل تعديل. ما ينطلق في الخلفية يظهر «تحقق ✓» عند فتح التطبيق.
- يبقى كل شيء ضمن الخطة المجانية لـ Cloudflare (طلب كل دقيقة).
- البيانات على الخادم: اشتراك الإشعار والتنبيهات والمنطقة الزمنية فقط، بدون مشترياتك.

### الاختبارات
```bash
cd worker && npm ci && npm test        # تشفير Web Push وتوقيع VAPID مقابل مكتبة مستقلة
node worker/test/integration.mjs       # الخادم محلياً (wrangler dev) مع خدمة push وهمية
node tests/push-e2e.cjs                # التطبيق + الخادم + push كامل على محاكاة آيفون
```

## التحديثات

عند تعديل أي ملف، غيّر `VERSION` في `sw.js` (مثلاً من `v2` إلى `v3`) ليحصل المستخدمون على النسخة الجديدة.

## الاختبار

```bash
npm i -g playwright   # إن لم يكن مثبتاً
node tests/e2e.cjs        # كل الميزات
node tests/live-e2e.cjs   # البث المباشر (سوق مفتوح، ويكند، وانقطاع البث)
```
`tests/e2e.cjs` يختبر 68 حالة: الأسعار الحية والحسابات، الفضة، سعر المحل، الأطر الزمنية الأربعة والجدول، الحاسبة، أنواع التنبيهات الثلاثة، المشتريات والبيع، العملات، النسخة الاحتياطية، ترحيل بيانات النسخة السابقة، العمل بدون إنترنت، والمسارات النسبية.
